# homebrew-apps

Homebrew tap for apps by boraoku.

```sh
brew install boraoku/apps/onefolder
```

| Formula | What it is |
| --- | --- |
| `onefolder` | [OneFolder](https://github.com/boraoku/onefolder): sync local folders to OneDrive and external drives with rclone, from a calm terminal app |

Formulas are generated by cargo-dist from each release of the app and pushed here by its release workflow.
